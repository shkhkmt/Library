# Library App

A simple, interactive web application to manage your personal book collection. Add new books, mark them as read or unread, and delete entries—all in a clean, responsive card-based interface.

# Features

* Add Books – Click the New Book button to open a modal form. Enter the title, author, number of pages, and whether you have read the book.

* Display Books – Books appear as stylish cards, each with a colored border indicating read status (blue = read, red = not read).

* Toggle Read Status – Click the Read / Not Read button on a card to update its status; the border color and button text change instantly.

* Delete Books – Remove any book from your library with a single click.

* In-Memory Storage – All books are stored in a JavaScript array during the current session (no database or local storage required).

# Technologies Used

* HTML5 – Structure and semantic markup

* CSS3 – Grid layout, responsive design, custom styling

* JavaScript (ES6) – Dynamic DOM manipulation, event handling, object-oriented programming (prototypes)
